🎮 Tic-Tac-Toe Game

A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

🚀 Features

🎯 Two-player gameplay

❌ Player X and ⭕ Player O

🏆 Detects the winner

🤝 Detects draws

🔄 Reset/restart the game

📱 Simple and responsive interface

🛠️ Technologies Used

HTML5

CSS3

JavaScript

📂 Project Structure
tic-tac-toe/
│
├── index.html

▶️ How to Run

Clone the repository:

git clone https://github.com/attreshreya05-blip/tic-tac-toe.git


Open the project folder:

cd tic-tac-toe


Open index.html in your browser.

You can also use VS Code + Live Server to run the project.

🎮 How to Play

Player X starts the game.

Players take turns selecting an empty square.

The first player to get three marks in a row wins.

If all squares are filled without a winner, the game ends in a draw.

Use the reset button to start a new game.
